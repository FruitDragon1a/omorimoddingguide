OMORI MODDING GUIDE

Setup & Prerequsites

Like the title suggests, this is a Step 0 towards getting your mod setup for creation. We’ll go over what programs you'll need for different types of mods and how to extract the game's files into formats usable in modding.

Basic Requirements

These are all the things you will need for making any mod in OMORI.

OMORI

This should be obvious. But to be specific, you’ll want a v1.08 Steam release of the game in English. (This means that most pirated copies will run into issues when using some resources or playing specific mods.) You’ll also need to know where it is installed, for which you can locate game files by going to the gear-shaped “Manage” icon on OMORI’s Steam page in your library, hovering over “Manage” in the dropdown, and clicking “Browse Local Files".


OneLoader

This is the tool used to load OMORI mods and decrypt the game's project file. Its page has detailed explanations on how to install it.


BundleTool

This is not technically required, but it is a tool to compile your mods, which is much easier than doing manually. Also, don’t put this in the mods folder. This is for much later, when you’re ready to export your finished mod for others to play.


From here, all you need to do is load up OMORI and go to the Decrypt section of the mod menu. Then set the decrypt settings to basegame (If you want any loaded mods embedded in your mod you can put everything) and select yes for generating an RPG Maker MV project. Then start the decryption. You’ll now have a decompiled project file for your mod, usually called a Playtest Folder.

Editing/Adding Gameplay Elements

You’ll need RPG Maker MV. It’s usually $79.99 USD, but it often goes on sale for about $7.99-$12.99 USD during any seasonal Steam Sale. In addition the OneMaker MV extension is greatly recommended for larger scale projects.

Editing/Adding Maps

On top of RPG Maker MV, you will also need Tiled, an external program that with plugins, OMORI can convert into maps for ingame use. The original game uses the 1.0.3 version of the program, and without plugin editing, you must use this version. However with this fixer plugin, the latest version can be used as well, which is recommended for extra features and stability.

Editing/Adding Plugins

You gotta know JavaScript, or at least be able to understand it. It helps if you have knowledge of another coding language, even if you don’t know JavaScript specifically. With plugin programming, any IDE will work, and our personal preferences were listed above. If you want to learn Javascript, there’s a ton of free tutorials online. Other resources include the MDN Web Docs, W3Schools, and GeeksForGeeks, especially if you’re just looking up how to do something specific (such as syntax or a certain method). The Internet is your friend when it comes to code!

Now with your Playtest Folder and all the programs you need for your mod, you're ready to begin!
